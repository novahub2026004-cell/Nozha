# التحقق من النسخة

- نجح `npm test`: ترحيلات قاعدة البيانات من 0001 إلى 0011، فصل بيانات الفروع، حساب التقييم مع البيانات الناقصة، تسليم التقارير والجودة، تصحيحات المدير العام وسجلها، ومنع مدير الفرع من تعديل حضور الأيام السابقة.
- نجح `npm run build` باستخدام قيم اتصال توضيحية لغرض البناء.
- تحقق المتصفح من تحميل Cairo المحلي ومن عرض نسخة الكمبيوتر والهاتف دون تجاوز عرض الصفحة.
- صور docs/screenshots مأخوذة من صفحة /preview التي تستخدم مكونات لوحة المتابعة الفعلية، مع بيانات توضيحية.

لم يتم ربط أو اختبار حسابات Supabase حقيقية أو نشر التطبيق على استضافة، لعدم توفير بيئة العميل. يلزم اختبار تسجيل الدخول والتزامن والتخزين على مشروع العميل بعد الربط.
