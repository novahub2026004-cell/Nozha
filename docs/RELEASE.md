# تغييرات النسخة 0.2

- تضمين ملفات Cairo محليًا مع ترخيص الخط، وتصميم موحد بقائمة جانبية وبطاقات واضحة وشاشة هاتف متجاوبة.
- إعداد 1 مدير عام و9 مديري فروع بكلمات مرور مستقلة، وإدارة حسابات المديرين من التطبيق.
- تقييم تشغيلي مفصل بأوزان قابلة للتعديل، وعدم إظهار البيانات الناقصة كتقييم نهائي.
- تصحيح التقارير بواسطة المدير العام مع السبب وسجل التعديلات، وتصحيح الحضور القديم.
- تسليم الجودة والتقارير في معاملات كاملة، وإصلاح حساب الجودة لمديري الفروع.
- حماية الحسابات الموقوفة ومنع التخزين المحلي لصفحات وبيانات المستخدمين في service worker.
- اختبارات محلية للصلاحيات والعمليات والتقييم، وGitHub Actions للبناء والتحقق.

هذه نسخة كود جاهزة للربط والنشر. تشغيل حسابات العميل فعليًا يحتاج مشروع Supabase ومتغيرات البيئة واستضافة.
